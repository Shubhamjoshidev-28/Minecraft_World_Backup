# User Guide

## Joining As A Java Player

1. Open Minecraft Java Edition.
2. Open Multiplayer.
3. Select Add Server.
4. Enter the provided server address.
5. Join.

### Supported Java Clients

* Official Minecraft Launcher
* TLauncher
* PojavLauncher

---

## Joining As A Bedrock Player

1. Open Minecraft Bedrock.
2. Open Servers.
3. Select Add External Server.
4. Enter server address.
5. Enter Bedrock port.
6. Join.

---

## Common Issues

### Unable To Connect

Check:

* Internet connectivity
* Server status
* Correct address
* Correct port

---

### Authentication Issues

Verify:

* Correct username
* Supported client version
* Compatible launcher

---

### Version Issues

The server supports multiple versions through:

* ViaVersion
* ViaBackwards

However, extremely old versions may not be supported.

---

## Recommended Client Versions

Use the latest stable Minecraft release whenever possible.

---

## Reporting Issues

When reporting problems provide:

* Client Type
* Minecraft Version
* Error Message
* Screenshot
